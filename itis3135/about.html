About

This page is built in part to demonstrate my work for the Charlotte course ITIS3135: Front-End Web Application Development, taught in sections run by Mr. von Briesen. This course focuses on helping students gain relevant experience with front-end web application development through hands-on website projects.

Throughout the course, students build multiple connected websites using different tools, techniques, validators, and development workflows. More information about the course can be found at Mr. von Briesen's course website .

Tools Used in This Course

  • VS Code
  • Emmet within VS Code
  • SFTP through FileZilla
  • Git through GitHub Desktop and GitHub.com
  • Various browser developer tools
  • The Accumulus Validator

Sites Built During the Course

  • Personal home portfolio
  • This course site
  • Design firm site
  • Crappy Page
  • Whimsical product company
  • Student, colleague, or peer management tool
  • Client project website

The goal is to make sure each site is clearly connected, organized, validated, and designed with a consistent look and feel. All pages within this course site should share the same header, footer, navigation, and stylesheet.
